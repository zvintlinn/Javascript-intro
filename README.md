# Första uppgiften med javascript

Detta är det första jag lyckats åstadkomma i javascript. Här hade jag absolut inga förkunskaper och kände mig till en början orolig över att inte förstå vad jag gör och varför saker sker. Uppgifterna kommer från webbutvecklingsprogrammet vid MIUN och är en del av kursen som omfattar HTML, CSS och Javascript.

## Reflektioner kring labben

Jag måste ändå säga att jag överträffat mina förväntningar på mig själv under denna uppgift. Det är såklart alltid roligt när man börjat på ett nytt område och kommer till punkten där saker börjar lossna och kännas logiska, utvecklingskurvan är väldigt skarp uppåt. Jag hade en föraning av att Javascript kanske skulle vara svårare för mig än HTML och CSS. Allt kändes övermäktigt när jag tittade på koden och jag förstod inte hur jag skulle hitta logiken. När jag väl började och benade ned allt till små steg insåg jag dock ganska snabbt att det faktiskt inte var så farligt som det såg ut. Jag har absolut slitit mitt hår till och från, men det är på något sätt värt det när man väl lyckas komma på vad som gått snett och varför.

Jag har försökt använda mig av de metoder som vi fått lära oss är mer moderna, exempelvis template literals. Detta skrivsätt föll sig mycket mer naturligt för mig och eftersom det ändå verkar vara en metod att sträva efter idag så har jag försökt befästa det.

Jag upplever trots allt att Javascript är det område som kanske fångat mitt intresse alla mest hittills i kursen. Det motiverar mig att känna att jag faktiskt förstår när det till en början kändes så pass svårt. Jag blir nog sporrad av att det är lite knivigt ibland!

Mina förhoppningar framåt i nästa moment är att få en bättre förståelse för hur javascript faktiskt implementeras på webbplatser. Jag tror att den kunskapen kommer bidra till en ännu bättre logik i hur koden i sig fungerar.

## Noteringar

Jag valde att inte skapa någon dev-branch i detta projekt. Min tanke med detta var att varje enskild uppgift var så pass liten att det kanske bara skulle vara överflödigt. Speciellt när filerna inte är kopplade till någon webbplats. Detta kan ha varit fel av mig, men vill ändå skicka med att det var ett medvetet val.
